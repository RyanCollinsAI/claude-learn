# courses

Drop a pre-built curriculum here as a `.md` file. The skill globs this folder, and when the ask
matches one it skips the probe and teaches straight from the file.

Ships empty on purpose. A course is a real reading path in a real order, vetted by a person - not
something worth shipping a generated example of.

State two things in the opening lines of the file, because that is all the skill reads to decide
whether to load it:

1. What the course covers.
2. What should trigger it - the phrasings someone would actually use.

Then the track itself: sections in teaching order, each item with its link, and a line on why it is
there and what to skip. Links are copied exactly and never paraphrased.
